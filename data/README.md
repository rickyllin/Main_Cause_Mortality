# data/ — 資料說明

```
data/
├── raw/                 原始資料（不修改）
│   ├── lung_cancer_incidence_1979_2022.csv     癌症登記：肺癌等各癌別發生率
│   └── mohw_cause_of_death/                    衛福部死因統計「各縣市」統計表（xls）
├── external/
│   └── county_boundary/                        內政部縣市界線 shapefile（1140318 版）
└── processed/           由 src/01_preprocess.py 產生
    └── lung_age_std_county_year.csv            縣市 × 年份矩陣（21 × 44）
```

## raw/lung_cancer_incidence_1979_2022.csv
癌症登記資料，每列為「診斷年 × 性別 × 縣市 × 癌別」。

| 欄位 | 說明 |
|---|---|
| 癌症診斷年 | 1979–2022 |
| 性別 | 全／男／女（本研究取「全」） |
| 縣市別 | 全國＋22 縣市（本研究排除「全國」與連江縣） |
| 癌症別 | 45 個癌別（本研究取「肺、支氣管及氣管」） |
| 年齡標準化發生率 WHO 2000… | 每 10 萬人口，WHO 2000 世界標準人口 |
| 癌症發生數 | 新診斷個案數（含千分位逗號字串；貝氏模型使用） |
| 平均年齡／年齡中位數／粗率 | 診斷年齡與粗發生率 |

## raw/mohw_cause_of_death/
檔名 `roc<民國年>_county.xls`：109、110、111、112、114 年（西元 2020–2023、2025；**缺 2024／民國 113 年**）。
每個檔案每個縣市一張工作表，`<縣市>2` 為「死因別」統計表（表 2），本研究取 ICD-10 `C33-C34`（氣管、支氣管和肺癌）列的
合計／男／女標準化死亡率。

## external/county_boundary/
內政部國土測繪中心「直轄市、縣（市）界線」1140318 版；原始 CRS 為 TWD97[2020]，繪圖時轉換。名稱用「臺」，程式中轉為「台」。

## processed/
| 檔案 | 說明 |
|---|---|
| `lung_age_std_county_year.csv` | 縣市（21，已排除連江縣）× 年份（1979–2022）的年齡標準化發生率，所有分析的共同輸入 |
| `lung_age_std_county_year_with_lienchiang.csv` | 含連江縣、保留缺值的版本（git 不追蹤，執行 01 時產生） |

## 注意
- 發生率（癌症登記）與死亡率（死因統計）是**不同資料來源**，只有 2020–2022 年重疊。
- 完整 1979–2022 死亡率序列尚未取得；取得後放入 `raw/`，並仿 `06_mortality.py` 加入處理即可。
